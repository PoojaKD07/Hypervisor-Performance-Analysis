# Data Dictionary

| Column | Meaning |
|---|---|
| Hypervisor | Tested virtualization platform |
| Type | Hypervisor category used in the lab |
| Guest OS | Guest operating system |
| CPU | Allocated virtual CPU resources |
| Memory | Allocated VM memory |
| Disk GB | Configured virtual disk size |
| Execution Time s | Sysbench total execution time |
| Total Events | Number of benchmark events completed |
| Events/sec | Sysbench throughput |
| Min Latency ms | Minimum observed latency |
| Avg Latency ms | Average observed latency |
| Max Latency ms | Maximum observed latency |
| P95 Latency ms | 95th percentile latency |
